🔑 Personal Token 设置(💡 按账号显著提升 GitHub Search 配额)

推荐使用 Fine-grained Token(细粒度,可零权限,比 Classic 更安全)
  1. GitHub 登录后,右上角头像 → Settings(个人设置,不是仓库设置)。
  2. 左侧菜单拉到底 → Developer settings(开发者设置)。
  3. 展开 Personal access tokens → 选择 Fine-grained tokens(不要选 Classic Tokens,经典 Token 权限太大,泄露即全账号风险)。
  4. 点右上角 Generate new token:
    • Token name:随便填,比如「本站 GitHub 搜索」。
    • Expiration:选 90 天(到期自动失效最安全)。
    • Repository access → 选 Public Repositories (read-only)。不要选 All repositories,不需要。
    • Permissions 板块:所有权限保持默认 No access,不要勾任何东西。
  5. 最底下点 Generate token,复制以 github_pat_ 开头的字符串,立刻粘贴到上面的输入框。
  6. ⚠ Token 只显示一次,关闭页面后再也看不到,丢了重新生成一个就行。

🔒 Token 只保留在当前标签页的 JavaScript 内存,不会写入 localStorage、sessionStorage、IndexedDB 或 Cookie;仅在浏览器直连 https://api.github.com 时作为请求头发送。
刷新或关闭页面后自动失效。请勿输入 GitHub 密码,也不要在来源不可信的页面中使用 Token。

🎯 什么时候需要设置 Personal Token(对照以下任意 1 条即建议填写 Fine-grained Token)
  1. 搜索频次较高:单人次连续搜索、翻页 ≥ 3 次/分钟,或同一时间段内切换筛选器、刷新热门 ≥ 5 次,未认证配额按出口 IP 计算,叠加后极易触发 403 限流。
  2. 多人共用同个公网出口 IP:同事共享公司网络 / 校园网 NAT / 公共 Wi-Fi / 机房代理出口,多人同时搜索即共用未认证出口 IP 配额,人均配额被摊薄,稳定度严重不足。
  3. 连续深度检索场景:需要翻到 10 页后、按多种排序/语言组合比较结果、批量浏览 Top 200+ 仓库,配额和稳定性要求显著高于单次查找。
  4. 运营商公网段被 GitHub 区域 403:部分移动/广电/小运营商出口被 GitHub 直接拦截(哪怕 0 请求也报 403 blocked due to IP),使用 Fine-grained Token 配合合法认证可解除大多数拦截。
  5. 部署到公共服务场景:本站作为团队共享工具提供给同事、合作伙伴使用时,建议引导每位用户独立填写 Token,已认证配额按账号独立计算,避免互相挤占配额。
✅ 无需填写的情况(保持默认未认证即可):单次检索少量仓库、每人独立公网 IP 无共享出口、仅偶尔查询关键词或查看近期热榜仓库。

🛡️ 本站功能说明 功能版本:v3.0.001 项目地址：https://github.com/Ozero-top/Github-Search

本站是独立开发的浏览器端公开仓库检索工具。默认情况下,页面直接调用 GitHub REST Search API, 并在本地完成查询组合、结果展示与可选排序。本站不隶属于 GitHub,不代表 GitHub,也不会修改 GitHub 平台中的仓库数据。

当前提供的功能
  • 公开仓库搜索:支持关键词、GitHub qualifier 语法以及语言、Star、更新时间、匹配字段和排序筛选。
  • 查询辅助:对部分中文查询和多词查询生成组合条件;用户手写的同类 qualifier 优先于界面筛选项。
  • 结果展示:展示仓库名称、描述、Topics、License、状态、统计指标、语言、更新时间及相关链接。
  • 关键词高亮:优先使用 API 返回的 text-match 信息;不可用时在浏览器本地进行文本匹配。
  • 本地二次精排:可选功能,仅对当前页已返回的结果重新排序。排序结果属于本站派生展示,不会改变 API 数据或 GitHub 搜索索引。
  • 近期热榜仓库:提供月榜、周榜、发现榜三种模式,默认显示月榜。
    • 月榜:近 30 天创建 · Star≥50 · 按总 Star 排序,展示前 100 项。
    • 周榜:近 7 天创建 · Star≥20 · 按总 Star 排序,展示前 100 项。
    • 发现榜:近 7 天更新 · Star>10 · 随机 100 个最近更新项目,客户端 Fisher-Yates 洗牌,每次刷新重新随机排列,让更多开源项目被发现。
    支持中文项目 / English 切换,项目语言根据仓库名称和 API 返回的仓库描述近似识别。该榜单由本站派生展示,不是 GitHub Trending 或 GitHub 官方排名或推荐。
  • 本地状态:搜索历史保存在当前浏览器;查询条件和分页写入 URL Hash;短期结果缓存在当前页面内存中。
访问方式与数据边界
  • 默认直连:未设置代理时,请求由浏览器直接发送至 https://api.github.com。
  • Personal Token:可选用于 GitHub API 身份验证。Token 仅在直连官方 API 时发送,与第三方代理模式互斥。
  • Token 生命周期:只保留在当前标签页内存,不会写入浏览器持久化存储;刷新或关闭页面后失效。本机恶意软件、恶意扩展或被控制的设备仍可能读取页面中的敏感数据。
  • 第三方代理:代理模式不携带 Token。代理服务由独立第三方运营,其可用性、响应内容、日志和隐私规则以对应运营方说明为准。
  • 查询范围:本站当前面向公开仓库搜索,不提供代码、用户、Issue、Pull Request 或私有仓库搜索。
  • 数据限制:结果受 API 索引状态、速率限制、返回上限、缓存及 incomplete_results 状态影响;具体仓库信息应以对应 GitHub 仓库页面为准。
